1. 背景

  • 今天折腾因为rsync局域网传输文件极慢而折腾路由器的经历时,发现路由器无法
    打开ipv6防火墙导致电脑的ipv6能被外网设备直接ping,终于决定给电脑安装防火墙

2. 执行

2.1. archlinux(GNU/LINUX)的主流防火墙方案调研

2.1.1. UFW vs firewalld

  UFW firewalld
---- ------ --------------
特点 简单 灵活
管理方式 直接配置规则 zone / service
适合 简单服务器 桌面、多网络、复杂场景
学习成本 低 中
  1. UFW

    简单易用，适合只需要开放几个端口的机器。

    sudo ufw allow 22/tcp
sudo ufw enable
  2. firewalld

    使用 zone 管理不同网络，适合桌面、多网卡、VPN、容器等场景。

    sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=home --add-service=samba
  3. 推荐
    简单需求：UFW
复杂网络环境：firewalld
想学习底层防火墙：nftables
Arch Linux 桌面机：推荐 firewalld

2.2. 选型结论

  • 用firewalld:因为我是桌面linux,需要不同场景快速切换防火墙配置,规则比较复杂,
    ufw适合给运行单一固定服务的服务器使用

2.3. DONE 安装firewalld并开启ipv6和ipv4防火墙,写基本的配置

3. 小结

  • firewalld重点小知识
    • zone:一个配置文件,常与interface绑定
    • interface:一个接口设备(loop设备,tun设备或者有线网卡和无线网卡,或docker产生的虚拟网卡)
      常通过绑定zone于是选择配置(zone就像是一套预设配置,可以快速切换,比如有"home"zone,"trusted"zone.
      以及"public"zone;区分不同场景)
    • rich-rule:绑定zone

  • 目前的操作
    以下是目前被激活的zones
    注意Meta这个tun设备默认绑定trusted zone,所有流量放行,

    shyweeds@archlinux ~> sudo firewall-cmd --get-active-zones
home
  interfaces: enp1s0 wlp2s0
trusted
  interfaces: Meta
public (default)

    以下是我对home这个zone的修改,
    home这个zone未匹配的流量全部REJECT,
    注意其中的dhcpv6-client作用是给我的ipv6动态ip地址的分配提供支持,

    shyweeds@archlinux ~> sudo firewall-cmd --zone=home --list-all
home (active)
  target: %%REJECT%%
  ingress-priority: 0
  egress-priority: 0
  icmp-block-inversion: no
  interfaces: enp1s0 wlp2s0
  sources:
  services: dhcpv6-client
  ports:
  protocols:
  forward: yes
  masquerade: no
  forward-ports:
  source-ports:
  icmp-blocks:
  rich rules:
  rule family="ipv4" source address="192.168.1.0/24" service name="ssh" accept
