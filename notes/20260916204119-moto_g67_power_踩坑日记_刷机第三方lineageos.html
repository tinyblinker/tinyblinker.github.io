  • !!!!! 第三方系统底包版本不能低于CN的出厂系统底包版本,否则变砖
  • !!!!! 禁止刷回原厂系统,因为当前系统安全更新更new,会导致触发防回滚变砖

5. 关键结论速查

5.1. 分区布局 (实测 getvar)

分区 类型 大小 说明
recovery raw 128 MiB 独立存在, 非合并进 boot
boot raw 96 MiB 内核 + recovery ramdisk
init_boot raw 8 MiB generic ramdisk
vendor_boot raw 96 MiB GKI 厂商 ramdisk + dtb
  • recovery.img (128 MiB) 对应 recovery 分区, 不是 boot 分区.
  • recovery.img 是 v4 头,只含 ramdisk (kernel_size=0) 的镜像.

5.2. A/B 机制要点

  • payload.bin 格式的 ROM 永远刷到 非活跃槽位, 刷完切过去启动.
  • 出厂新机通常只有一个槽被填充; 非活跃槽在第一次官方 OTA 前是空的.
  • 第三方 ROM 的 payload 不含 bootloader / modem 等专有固件分区.

6. 踩坑清单 (全部)

6.1. 坑1: fastboot boot recovery.img 无效

  • 现象: Sending OKAY 后 Booting FAILED, 手机闪 "no valid os".
  • 原因: 该机 bootloader 不支持临时 boot (Moto 常见限制).
  • 解决: 改用 fastboot flash recovery recovery.img 永久刷入.
  • 注意: "no valid os" 只是提示, 临时 boot 不写任何分区, 原系统无损.

6.2. 坑2: 误以为 recovery 合并进 boot

  • 现象: 疑惑 recovery.img 该刷 boot 还是 recovery.
  • 解决: fastboot getvar has-slot:recovery 返回 yes, 且
    recovery.img 大小 (128 MiB) 与 recovery 分区完全一致, boot 是 96 MiB.
  • 结论: 就是刷 recovery 分区.

6.3. 坑3: recovery 里 adb 显示 unauthorized

  • 现象: 进 recovery 后 adb devices 显示 unauthorized.
  • 原因: recovery 的 adbd 不认系统里授权过的电脑密钥 (数据在 /data, recovery 不挂载).
  • 解决: 无需解决, 在手机上选 Apply update -> Apply from ADB 进入
    sideload 模式后无需授权, 状态变为 sideload.

6.4. 坑4: slot B 未填充 (出厂从未 OTA)

  • 现象: fastboot set_active b 报
    "Bootloader images on target slot b are not valid!! There is risk of bricking HW".
  • 原因: 设备出厂后从未 OTA, slot B 的 bootloader 等固件是空的.
  • 解决: 先 sideload copy-partitions 脚本把 slot A 固件复制到 slot B.
  • 警告: 千万别再跑一次 set_active b 强制切换 (会硬砖进 EDL).

6.5. 坑5: 用旧版官方固件填充 slot B 是危险的

  • 现象: 想用目录里 XT2533-4_…_15_V2VT35.34-33-25 CFC 包填充 slot B.
  • 原因: 该包是 Android 15 (V2VT35), 比设备当前 Android 16 (W1VT36H) 旧,
    且 bootloader 更旧 (ST13.3 vs ST27.7), 降级会触发 anti-rollback 硬砖.
  • 结论: 该 CFC 包只能救砖/回退, 不能用于填充 slot B.用 copy-partitions.

6.6. 坑6: copy-partitions 报签名验证失败是正常的

  • 现象: sideload copy-partitions-20220613-signed.zip 弹
    "Signature verification failed".
  • 原因: 脚本非 LineageOS 官方签名.
  • 解决: 选 Continue / Yes 继续即可.
  • 验证: 跑完后 fastboot set_active b 不再报 not valid, 返回 OKAY.

6.7. 坑7: "Logical partitions are mapped"

  • 现象: sideload ROM 报
    "Logical partitions are mapped. Please reboot recovery before installing an OTA update".
  • 原因: format data / 前序操作使 super 内的逻辑分区处于已映射状态.
  • 解决: Advanced -> Reboot to recovery 后再 sideload, 中间不要再做别的操作.

6.8. 坑8: GApps sideload 报 error 21 / status 2 (核心未解坑)

  • 现象: 刷 MindTheGapps 全部版本都报
    "failed to verify whole-file signature / Signature verification failed / error:21 / status 2".
  • 原因: ROM 是 user 版 (指纹 …:user/release-keys), LineageOS recovery 源码里
    ask_to_continue_unverified() 在 user 版直接 return false, 不弹
    "Install anyway?" 提示    , 直接拒绝非本 key 签名的包.
  • 关键: 刷 ROM 本体能成功 (同 key), GApps (外 key) 被拒.

6.9. 坑9: 重签名方案不可行

  • 现象: 想用 ROM 签名密钥给 GApps 重签名.
  • 原因: ROM 用作者自定义私钥 (otacert: CN=Quartz750, email=123@456.com),
    非公开 test-key; 重签名必须持有私钥, 我们只有公钥, 密码学上无法完成.
  • 结论: 方案四死路, 需改走其他路线 (见"待办").

7. 严谨刷机步骤 (已验证的完整流程)

7.1. 阶段0: 前期确认

adb devices -l            # 确认设备在线
fastboot getvar current-slot
fastboot getvar has-slot:recovery   # 确认是否有独立 recovery 分区
fastboot getvar slot-successful:b   # 判断 slot B 是否曾启动 (判断是否 OTA 过)

7.2. 阶段1: 刷 recovery

adb reboot bootloader
fastboot devices          # 应显示 fastboot (不带 d)
fastboot flash recovery recovery.img   # 永久刷入, 不要用 fastboot boot
fastboot reboot recovery

7.3. 阶段2: 同步分区 (仅当从未 OTA / slot B 为空时必做)

# recovery 中: Apply update -> Apply from ADB
adb sideload copy-partitions-20220613-signed.zip   # 弹签名失败选 Continue
# recovery 中: Advanced -> Reboot to recovery
# 验证: fastboot set_active b 应返回 OKAY 而非 not valid

7.4. 阶段3: 格式化并刷 ROM

# recovery 中: Factory reset -> Format data
# recovery 中: Advanced -> Reboot to recovery (重要, 避免逻辑分区已映射)
# recovery 中: Apply update -> Apply from ADB
adb sideload LineageOS23.2-UNOFFICIAL-PORTOV.zip
# 刷完 Reboot system now; ROM 会被写到非活跃槽并切过去启动

7.5. 阶段4: 刷 GApps (当前被坑8阻塞, 见待办)

adb sideload MindTheGapps-16.0.0-arm64-XXXXXXXX.zip
# 若已开过机再补刷 GApps, 需再 Factory reset / Format data

9. 常用参考命令

fastboot getvar all                       # 查看全部 bootloader 变量
fastboot set_active a                     # 切回 slot A
adb shell getprop ro.boot.slot_suffix     # 查看当前槽位 (开机后)
unzip -p <rom.zip> META-INF/com/android/metadata   # 查看 ROM 元数据
openssl x509 -in <otacert> -noout -subject -fingerprint -sha256  # 查看签名证书
