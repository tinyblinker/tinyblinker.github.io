1. 设备信息

  • 商用名称:Motorola moto g67 power 5G
  • 中国对应机型:Moto G100 (2025)
  • Codename: portov
  • SoC:Qualcomm Snapdragon 7s Gen 2 / SM7435
  • shipped Android:Android 15
  • 典型型号:XT2533-3 / XT2533-4 / XT2533-5
  • 本机重点型号: XT2533-4 (中国版 Moto G100 2025)
  • 电池:7000 mAh
  • 屏幕:6.7" / 120 Hz / 1080x2400

参考:

  • parrot-66-dev/android_device_motorola_portov
  • 4PDA:Motorola G100 / G67 Power (2025)

2. 重要注意事项

2.1. 型号与 codename

XT2533-4 属于 portov 家族,因此在搜索第三方开发时应优先使用以下关键词:

portov
Moto G67 Power 5G
Moto G100 2025
XT2533-4
XT2533-3
XT2533-5
SM7435
Snapdragon 7s Gen 2

不要把 2021 年的老款 Moto G100 / Edge S 与 2025 年的 Moto G100 / G67 Power 混淆.

2.2. A/B 双槽

这台设备使用 A/B seamless update 架构.第三方 ROM / recovery 的刷写说明经常要求检查并同步两个 slot.

尤其注意:

  • 不要因为某个分区名称或镜像“看起来一样”就跨版本,跨区域直接刷.
  • 中国 RETCN 与 RETIN/RETEU/RETID 等渠道固件要单独核对.
  • 使用自定义 ROM 时不要重新锁定 bootloader.
  • 在动 boot / vendor_boot / dtbo / vbmeta / super 前,始终准备好完整官方救砖固件.

2.3. Anti-Rollback

公开的 portov ROM 项目中已经出现关于 ARB(Anti-Rollback)Index 的处理说明.不同 firmware 基线之间不能只看 Android 大版本,还需要检查 bootloader / ARB / CID 等状态.

2.4. 数据清除

第三方 ROM 特别是跨版本/跨厂商移植 ROM 常要求 Format Data.不同项目的具体要求不同,以对应项目 README 为准.

14. 十二,建议的研究顺序

对于 XT2533-4 / portov,建议按这个顺序研究:

  1. 主 device tree
  2. sm7435-common
  3. SM7435 kernel
  4. Portov vendor
  5. TWRP
  6. Hello UI port
  7. 4PDA 社区讨论

这样可以先搞清楚:
device tree -> common -> kernel -> vendor -> recovery -> ROM

而不是一上来只找一个“能刷的 zip”.

15. 十三,风险记录

刷机前记录至少以下信息:

fastboot getvar all
fastboot getvar current-slot
fastboot getvar product
fastboot getvar is-userspace
fastboot getvar unlocked

并保存:

  • 当前 firmware 完整版本号
  • 当前 CID
  • 当前 active slot
  • 当前 ARB / rollback 相关状态
  • 关键分区备份
  • 官方 Motorola Rescue and Smart Assistant(RSA)救砖方案

严禁:

  • 在第三方 ROM 上重新锁 BL
  • 不核对型号就跨设备刷 boot/vendor_boot/dtbo/vbmeta
  • 不核对 ARB 就强行降级
  • 把 2021 年老 Moto G100 镜像误刷到 2025 年 portov
