1. A little thought of them

  • linux cli工具的本质不在于你记住她们的每一个选项,而只需要知道这个工具"为了什么经典问题"而设计,
    "最典型"的使用方法是怎么样的,用有限可控的心智模型去理解她们,并强迫自己用无补全无提示的裸bash天
    天书写她们,于是心智模型得以建立,那些看起来令人眼花缭乱的cli参数也会因为心智模型的建立而自然而然
    地被在正确的场合以恰到好处的心流模式被想起,被尽可能多地统一在一个心智模型中.

2. Intro

Like 'Rust by example',I always thought of that learning by small atomic examples
is always the best way to get through an unfamilier thing!
本笔记专注于收集日常中经常用到的莫名其妙甚至奇奇怪怪的bash脚本或linux命令行小妙招

3. awk

  • (逐行处理)awk 的基本形式通常是 条件 { 动作 }:符合条件的行执行动作;省略条件时,就处理每一行.

score.txt:

小林 88
小王 76
小陈 93

Usage of 'awk':

[shyweeds@archlinux]$ awk '$2 > 80 { print $1 }' ./test.txt
小林
小陈

4. sed

  • sed 是面向文本流的编辑工具,常用来替换,筛选,删除或修改文本.它通常逐行处理输入.

1.txt:

apple 10
banana 20
apple 30

Usage of 'sed':

[shyweeds@archlinux]$ sed 's/apple/happy/' ./1.txt
happy 10
banana 20
happy 30

删除第二行

sed '2d' data.txt

删除空行

sed '/^$/d' data.txt

5. find

  • search for files in a directory hierarchy

在当前目录下递归查找"main.rs"(可写正则表达式)的文件(-type file)

find . -name main.rs -type f

6. grep

  • print lines that match patterns

忽略大小写(-i),按行找出由find筛选出来的,目录名含有"project"(忽略大小写)的main.rs条目

find . -name main.rs -type f | grep -i project

7. nohup

  • run a command immune to hangups, with output to a non-tty
[shyweeds@archlinux]$ nohup gammastep -O 4500 >/dev/null 2>&1 < /dev/null &
[1] 23081
[shyweeds@archlinux]$ jobs
[1]+  Running                    nohup gammastep -O 4500 > /dev/null 2>&1 < /dev/null &
